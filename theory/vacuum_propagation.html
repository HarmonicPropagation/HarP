Far Field Propagation¶

Since the HarP algorithm is limited by the longitudinal box size, to propagate the field far from the exit of the gas, it is convenient to solve the field propagation in vacuum using the Hankel transform. In this section, we derive the mathematical and numerical framework for this purpose.

Hankel transformation¶

For the sake of completeness, we remind the Hankel transform of order \(\nu\) of an arbitrary function \(f(r)\) [HankelTransform]:

\[F_\nu(k) = \int_0^\infty f(r)J_\nu (k r) r dr\]

and its inverse transformation:

\[f(r) = \int_0^\infty F_\nu(k)J_\nu (k r) k dk,\]

where \(J_\nu\) denotes the Bessel function of the first kind of order \(\nu\geq -1/2\). By construction, the Bessel function \(J_\nu\) satisfies the differential equation:

\[x^2 J_\nu''(x) + J_\nu'(x) + x^2 J_\nu(x) = \nu^2 J_\nu(x),\]

where the prime notation corresponds to the successive derivatives of \(J_\nu(x)\) with respect to \(x\).

Envelope equation in vacuum¶

In vacuum the paraxial Helmholtz equation for the field envelope of harmonic \(q\) reads:

(5)¶\[r^2 \partial_r^2 E_q + r \partial_r E_q + 2i \frac{q\omega}{c}r^2 \partial_z E_q = 0.\]

This could be directly derived from Eq. (2) noting that there is no variation of the background densities (in vacuum \(\Delta k_q = 0\) and \(\delta k_q = 0\)).

Let \(\tilde{E}_{q}\) be the Hankel transform of order \(0\) of the field envelope \(E_{q}\):

\[E_{q}(r,z) = \int_0^\infty \tilde{E}_{q}(k,z) J_0 (k r) k dk\]

and injecting in the paraxial Helmholtz equation Eq. (5), we obtain the differential equation for the Hankel transform:

\[-k^2 \tilde{E}_{q}(k,z) + 2i \frac{q\omega}{c} \partial_z \tilde{E}_{q}(k,z) = 0,\]

which admits the solution:

\[\tilde{E}_{q}(k,z) = \tilde{E}_{q}(k,z=z_0) \exp{\left[-i \frac{c k^2}{q\omega} (z-z_0)\right]}.\]

These properties are used to propagate the field far from the exit of the target as described below.

Numerical procedure¶

The field envelope at the end of the simulation box \(E_q(r,z=Lz)\) is calculated using the HarP algorithm. The numerical solution is used as an input for the propagation at any given longitudinal position \(z \geq Lz\). To compute the field far from the exit box, we apply the following three distinct steps:

  1. First, the Hankel transform \(\tilde{E}_{q}\) of the field envelope at the rear of the target is calculated according to:
    \[\tilde{E}_{q}(k,z=Lz) = \int_0^\infty E_{q}(r,z=Lz) J_0 (k r) r dr\]
  2. Second, it is propagated to an arbitrary position using:
    \[\tilde{E}_{q}(k,z) = \tilde{E}_{q}(k,z=Lz) \exp{\left[-i \frac{c k^2}{q\omega} (z-Lz)\right]}\]
  3. Finally, the field envelope is reconstructed from the inverse Hankel transform:
    \[E_{q}(r,z) = \int_0^\infty \tilde{E}_{q}(k,z) J_0 (k r) k dk\]

At each time slice, when the field reaches the simulation box limit, these three steps are applied to propagate the field. The vector \(k\) is uniformly distributed from \(0\) to \(\min(\pi / \Delta r, \alpha q\omega/c )\). The limit corresponds to the minimum between the Nyquist frequency and the paraxial approximation. It ensures that at least two points discretise the wavelength through the condition \(k<\pi / \Delta r\) (Nyquist limit). It also ensures that the angle between the wave and the optical axis remains small (paraxial approximation \(k_\perp \ll q\omega/c\)) through the condition \(k_\perp \ll \alpha q\omega/c\) where \(\alpha\) is an arbitrary number below unity. This discretisation is used to compute the Hankel transform integrals with a Riemann sum.

Note

As the transverse dimension is uniformly discretised in the HarP loop, the wavevector \(k\) is also uniformly discretised. However, for the numerical evaluation of the Hankel transforms, a discretisation based on the zeros of the Bessel function provides a more appropriate choice to ensure the grid resolves the oscillation of \(J_0\). We therefore plan to implement a non-uniform, Bessel-zero-based discretisation in future work.

This calculation is not part of the HarP algorithm but a branch inside the Diagnostics DiagFarField (practical application described in the namelist). It allows the efficient calculation of the field far from the exit of the gas without increasing the simulation box length.
